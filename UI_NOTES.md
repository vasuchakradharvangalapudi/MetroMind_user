# MetroMind UI Notes

The interface is intentionally styled like a practical university/public-transport operations application rather than an AI-themed landing page.

- Neutral white/grey application surfaces
- Dark utility sidebar
- Blue transit-system accent
- Compact data tables and form controls
- No gradient-heavy hero sections or decorative glow effects
- Responsive layout for laptop and mobile widths
- Dashboard uses simulated/synthetic network values; it is not connected to a real metro control API

For the presentation, start with Dashboard, then demonstrate Station & Alert Search, Document Similarity, and Station Name Correction.
